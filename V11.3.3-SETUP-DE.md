ACY V11.3.3 — Pet + Friends Reparatur
=====================================

1. In Supabase SQL Editor, run:
   `supabase/v11.3.3_pet_friends_quest_repair.sql`

2. Deploy V11.3.3.

Pet:
- Füttern: +35 Hunger, +5 Energie
- Spielen: +25 Laune, -15 Energie
- Streicheln: +10 Laune, +5 Energie
- Energie regeneriert passiv bis 100%.
- +5 Pflege-XP pro erfolgreicher Aktion, max. 4 Aktionen / Tag.

Friends:
- Accepted requests are repaired into both friendship rows.
- The Friends list also reads accepted requests directly as a fallback.
- Pending outgoing requests are shown, so sent-but-not-yet-accepted requests are no longer invisible.

No new npm dependencies.
