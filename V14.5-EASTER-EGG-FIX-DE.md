# ACYJANNIK V14.5 — Easter Egg Fix

Der Cosmic-Modus aus V14.4 war zwar im Code vorhanden, aber die Logo-Geste konnte wegen des umschließenden Links nicht zuverlässig ausgelöst werden.

## Auslöser

1. Auf der ACY-Club-Seite schnell **ACY** tippen.
2. Alternativ das **A-Logo zweimal schnell anklicken**.
3. Für QA kann die Club-Seite mit `#cosmic` geöffnet werden.
4. Escape schließt das Overlay wieder.

Der Easter-Egg-Code ist nun direkt über `window.__openAcyCosmicProtocol()` testbar, ohne einen sichtbaren Testbutton einzubauen.

Keine Supabase-Migration erforderlich.
