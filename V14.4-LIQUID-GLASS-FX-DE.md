# ACYJANNIK V14.4 – Liquid Glass FX & Sounds

V14.4 baut direkt auf V14.3 auf. Es ist kein Datenbank-Release, sondern ein UI-/Interaction-Release.

## Neu

- deutlich reichhaltigere Interface-Sounds, komplett synthetisch über Web Audio API
- unterschiedliche Sound-Signaturen für Klick, Erfolg, Reward, Level-Up, Pet-Aktion, Refresh, Spin, Toggle und Secret Unlock
- sehr dezente Hover-Sounds für interaktive Elemente
- Liquid-Glass Ripple bei Klicks
- stärkerer Press-/Hover-Effekt für Buttons
- Refresh-Buttons bekommen einen eigenen Whoosh-Sound
- geheimes ACY Cosmic Protocol als Easter Egg

## Easter Egg

Auf der Club-Seite `A`, danach `C`, danach `Y` tippen. Alternativ kann das ACY-Logo im Header doppelt angeklickt werden.

Dann erscheint ein Cosmic-Glass-Overlay mit dem vorhandenen Dragon-Pet-Artwork.

## Datenschutz / Technik

Die Sounds werden lokal im Browser erzeugt. Es werden keine Audiodateien geladen und keine Audio-Daten übertragen.

Die bestehende Einstellung `acy-ui-sounds-v1` bleibt erhalten. Wer Sounds deaktiviert hat, bekommt auch die neuen Effekte nicht zu hören.

`prefers-reduced-motion` wird für Ripple-, Stern- und Confetti-Animationen respektiert.

## Deployment

Keine Supabase-Migration notwendig.

V14.4 deployen und anschließend einmal hart neu laden, damit `?v=14.4.0` greift.
