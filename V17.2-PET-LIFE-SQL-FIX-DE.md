# ACYJANNIK V17.2 – Pet Life SQL Fix

V17.2 fixes a PostgreSQL type mismatch in the V17.1 migration.

The constraint-detection query compared `name[]` with `text[]`. The migration now explicitly casts `att.attname` to `text` before `array_agg`, so Supabase can execute it correctly.

Run once in Supabase SQL Editor:

`supabase/v17.2-pet-life-reliability.sql`

No existing Pet data needs to be reset.
