# ACY Club UI 2.0

- Mobile Club layout compacted and touch targets retained.
- Club section navigation is a horizontal rail on mobile.
- Club fold sections now behave as an accordion: one top-level section open at a time.
- Member directory remains list-based and gains a direct "Mein Profil" action.
- Profile/member imagery and card density reduced on mobile.
- Club Chat is explicitly marked LIVE with a red live indicator.
- Notification badge sizing prevents clipping.
- Existing Pet/Quest logic and Supabase RPC behavior were not intentionally changed.
