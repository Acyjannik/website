# ACY V12.8 – Dashboard Loading / Database Resilience Fix

Diese Version behebt ein Problem, bei dem ein langsamer oder fehlerhafter Supabase-/API-Request die komplette Initialisierung des Club-Profils blockieren konnte.

## Änderungen
- Profil, aktuelles Game und Pet werden priorisiert geladen.
- Optionale Bereiche werden parallel geladen.
- Einzelne langsame Requests haben ein 8-Sekunden-Limit und blockieren nicht mehr den Rest der Seite.
- Community Games werden nicht mehr von Rewards, Wheel, Notifications, Chat etc. abhängig gemacht.
- Fehler in optionalen Modulen bleiben in der Konsole sichtbar, während der Rest der Seite weiterläuft.
- Profil-XP für Profil-/Mitgliedsdauer-Aktionen blockiert das Rendern nicht mehr.
- Build-Marker: **ACY BUILD V12.8**

## Nach dem Deployment
1. V12.8 vollständig deployen.
2. Browser mit `Strg + F5` hart neu laden.
3. Wenn Games weiterhin leer bleiben, in der Browser-Konsole nach `[V12.8] Current Game skipped:` suchen. Dann ist der konkrete Supabase-Fehler sichtbar, ohne dass die ganze Seite hängen bleibt.
