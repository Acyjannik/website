# ACYJANNIK V15.1 – Mobile Dock & Navigation

## Änderungen

- Mobile Bottom-Dock bekommt sichtbare Live-Badges für:
  - Hinweise / Benachrichtigungen
  - Quests, wenn mindestens eine Quest abholbereit ist
  - Chat, wenn ungelesene Direktnachrichten vorhanden sind
- Badges werden automatisch aktualisiert, wenn die jeweiligen Daten neu geladen werden.
- Kurze, eindeutigere Bereichstitel:
  - ACY Club Chat → Club Chat
  - Freunde & Kontakte → Freunde
  - ACY Club Mitglieder → Mitglieder
  - Die besten Momente. → Clips
  - ACY Club Ranking → Ranking
  - Dein Club-Fortschritt. → Club-Fortschritt
  - ACY Club auf Discord → Discord
  - Deine Aufgaben → Quests
  - Meine Belohnungen → Belohnungen
  - Neuigkeiten → News
- Mobile Fold-Überschriften und Beschreibungen werden auf kleinen Displays kontrollierter skaliert.
- Bottom-Dock erhält größere Touch-Flächen, klarere Glass-Fläche und bessere Safe-Area-Unterstützung.
- Dock-Interaktion bekommt aktiven Zustand und Badge-Hierarchie.
- Versionsmarker: ACY BUILD V15.1.

## Keine Datenbankmigration

Für V15.1 ist keine neue Supabase-SQL-Migration erforderlich.
