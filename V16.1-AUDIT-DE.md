# ACYJANNIK V16.1 — Audit & Reliability Refresh

## Design
- Section artwork now uses the six approved reference artworks from the supplied ACY screenshot.
- No new AI artwork was generated.
- Mobile artwork sizes and summary rows tightened for small screens.

## Functions
- Daily-Serie refreshes on page focus/visibility and every 30 seconds while open.
- Daily-Serie uses the actual 24-hour cooldown timestamp.
- Quest progress is returned with the catalog in one RPC instead of one query per quest.
- Quest realtime remains enabled.
- Notifications refresh on visibility/focus.
- Push subscriptions are no longer destroyed by the PWA bootstrap.

## Notifications
- Automatic Daily-Serie-ready notification after 24h: In-App + Push + optional E-Mail.
- The hourly Vercel cron checks readiness.
- Dispatch log prevents duplicate sends for the same cooldown event.
- Existing 08:00 and 18:00 club greetings remain.

## Security
- Vercel security headers added.
- Push helper respects push opt-out.
- Internal notification email routing requires CLUB_EVENT_HUB_SECRET and a validated UUID.

## Supabase
Run once: `supabase/v16.1-notification-and-streak-ready.sql`

## Privacy
`datenschutz.html` updated for account/auth, XP, quests, Daily-Serie, pets, in-app notifications, web push, email categories, PWA, Supabase, Vercel, Discord and Twitch.
