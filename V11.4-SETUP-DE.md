ACY V11.4 — Progression Expansion

No Supabase migration is required.

Changes:
- Main dashboard no longer shows the separate Twitch live card.
- Twitch/ACY Connect remains on the dedicated profile connection section.
- Club progression now has 30 levels from 0 XP to 920,000 XP.
- New higher tiers include Ascended, Celestial, Eternal, Apex, Vanguard, Paragon, Overlord, Sovereign, Cosmic, Transcendent, Eternal Flame, Grandmaster, Omega, Apex Legend, Ultra, Infinity, Beyond and Hall of Fame+.
- Dashboard shows upcoming level milestones and XP sources.
- Achievement API now awards additional XP, event, game and quest achievements up to 1,000,000 XP.
