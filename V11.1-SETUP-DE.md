ACY V11.1 — Vote → Discord
==========================

No database migration is needed.

The existing Vercel environment variable is used:
  DISCORD_EVENT_WEBHOOK_URL

After deployment, when a Mod publishes a Community Vote:
1. The vote is written to Supabase.
2. The options are written to Supabase.
3. ACY sends a Discord message through the existing webhook.
4. If Discord is temporarily unavailable, the vote stays published and the Mod Center shows the Discord error.

Discord message example:

🗳️ NEUER COMMUNITY VOTE

Welche Game Night sollen wir machen?

Antworten:
1. Overwatch
2. Dead by Daylight
3. Roblox

🛡️ Veröffentlicht über den ACY Moderatorbereich.
