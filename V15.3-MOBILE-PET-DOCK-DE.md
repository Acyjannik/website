# ACYJANNIK V15.3 – Mobile Pet & Dock Refinement

## Änderungen

- Pet-Beschreibung auf Mobile überarbeitet: kürzer, moderner, ohne Tamagotchi-Referenz.
- Pet-Aktionen auf Mobile sauber als zwei gleich große Aktionen plus eine volle Danger-Aktion angeordnet.
- „Tier wechseln“ → „Wechseln“, „Tier abgeben“ → „Abgeben“ für bessere Lesbarkeit auf kleinen Displays.
- Mobile Bottom Dock neu priorisiert:
  - Pet
  - Quests
  - Chat
  - Hinweise
  - Glücksrad
- Übersicht wurde aus dem Bottom Dock entfernt. Die Seite bleibt über den oberen Bereich und den Nach-oben-Button erreichbar.
- Dock behält Live-Badges für Quests, Chat und Hinweise.
- Aktiver Dock-Eintrag erhält einen dezenten Liquid-Glass-Zustand.
- Hash-Navigation synchronisiert den aktiven Dock-Eintrag.
- Doppelte „Profil“-Navigation im Bereichsmenü entfernt.
- Build Marker: ACY BUILD V15.3.
- Asset Cache-Buster auf 15.3.0 angehoben.
