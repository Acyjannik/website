# ACYJANNIK V17.8 — Pet Admin Test + mehr Interaktionen

Nach V17.7 deployen und `supabase/v17.8-pet-admin-test-and-interactions.sql` einmal im Supabase SQL Editor ausführen.

## Admin
- Extra-Drehs für ein Mitglied gutschreiben
- Pet-Testmodus pro Mitglied an/aus
- Testmodus überspringt Pet-Tageslimits, Pet-Item-Verbrauch und Glücksrad-Cooldown; Rewards bleiben aktiv

## Pet
- Trainieren: 2×/Tag, +12 Pflege-XP, Energieverbrauch
- Erkunden: 2×/Tag, zufällige Snacks + AC Coins, Energieverbrauch
- Neue Interaktionen respektieren weiterhin Hunger/Laune/Energie statt neue Statuswerte einzuführen.

## Perks
Perks bleiben bewusst **ladungsbasiert statt zeitbasiert**. Das ist bei nur drei Pet-Stats übersichtlicher und verhindert, dass ein Bonus unbemerkt während einer Pause verfällt. Später können seltene zeitlich begrenzte Events separat dazukommen.
