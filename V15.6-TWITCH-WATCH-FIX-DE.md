# ACYJANNIK V15.6 — Twitch Stream-Time Fix

## Problem
The Twitch watch tracker previously sent a heartbeat only every 120 seconds while the
server rounded each heartbeat delta down to whole minutes. This discarded leftover seconds
on every heartbeat and could undercount watch time substantially.

## Fix
- Heartbeat interval reduced to 60 seconds.
- Server accumulates exact session seconds in `club_twitch_stream_sessions.duration_seconds`.
- Only newly completed whole minutes are added to `club_twitch_points`.
- Leftover seconds are preserved between heartbeats.
- Mobile/background tabs stop the active tracking session and resume with a fresh heartbeat
  when the page becomes visible again.
- Server heartbeat delta is capped at 150 seconds to avoid counting long browser suspension.
- Fixed first-time `stream_days` initialization in `add_twitch_watch_time` so a first stream
  starts at 1 day instead of using the number of watch minutes.
- No new tables are required. The existing Twitch SQL function should be replaced by the
  updated `supabase/v11_twitch.sql`.

## Important
Deploy the updated project and run the updated `supabase/v11_twitch.sql` once in Supabase.
Existing session data remains compatible.
