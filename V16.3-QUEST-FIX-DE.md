# ACYJANNIK V16.3 — Quest Reliability Fix

## Fixed
- **Kontakt pflegen** (`daily_friend`) now counts on the public `member.html` page itself, so opening another member profile works regardless of whether the user arrived via member directory, leaderboard, spotlight or pet link.
- The profile-view quest uses the Berlin calendar date to match the Club's daily quest period.
- Spotlight profile navigation also tracks the action before navigating; the public profile remains the authoritative fallback.
- **Glücksrad-Woche** progress is now awaited before the wheel UI refreshes, avoiding a race where the spin happened but quest progress was still stale.
- Restored the missing `renderClubLevelCatalog()` renderer that caused `renderClubLevelCatalog is not defined` during progression enrichment.
- All active asset/version markers are 16.3.0.

## Supabase
No new SQL migration is required if the V15.8/V16.1 quest SQL is already installed. This build uses the existing `increment_quest` and `get_my_quests` functions.
