# ACYJANNIK V17.3 — Pet Admin Test Controls

## Was neu ist
- Pet-Aktionen werden nach ausgeschöpftem Tageslimit sichtbar deaktiviert.
- Die Pet-Labels zeigen klar, wie viele Nutzungen heute noch verfügbar sind.
- Admins können die heutigen Pet-Limits, den Tagesvorrat und die Pet-Minispiele für ein ausgewähltes Mitglied zurücksetzen.
- Admins können den 24-Stunden-Cooldown des Glücksrads zurücksetzen. Die Dreh-Historie und die Wochenquest bleiben dabei erhalten.

## SQL
Nach dem Deployment einmal `supabase/v17.3-pet-admin-resets.sql` im Supabase SQL Editor ausführen.

## Sicherheit
Die beiden Reset-Funktionen prüfen serverseitig, ob der eingeloggte Benutzer in `admin_users` eingetragen ist. Moderatoren erhalten dadurch keinen Zugriff.
